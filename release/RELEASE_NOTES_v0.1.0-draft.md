# COMPASS core code 0.1.0-draft

This private-review release candidate contains the frozen v16.5 semantic analysis stages 01–22, the five main-figure scripts, data/input documentation, numerical checkpoints, static-site export, and release validation utilities.

Large public and provider-hosted inputs, including EPA ECOTOX, are obtained from their official services and are not mirrored in this compact code package. Users prepare the documented local inputs from those sources. The static explorer is a separate package built from frozen precomputed display results.

Before public release, the authors must approve a public license, repository name/visibility, final citation/contact metadata, release tag, and Zenodo DOI. Public release must be blocked if any numerical, site, checksum, secret, path, or large-file check fails.
