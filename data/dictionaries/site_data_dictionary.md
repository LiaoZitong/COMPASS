# Static explorer data dictionary

All site files are generated by `code/export_site_data.py`. They are outputs, not independent analytical inputs.

## `metadata.json`

Records site, analysis, manuscript, and SI versions; data-freeze and generation dates; source-output SHA-256 values; storage/display units; and release identifiers. `git_commit`, `github_release`, and `zenodo_doi` remain null until the corresponding release exists.

## `national_sequence.json`

One row per candidate species in the complete lower-5% national ordering. Ranks 1–20 reproduce the frozen sequence and contain dependence-adjusted `cumulative_expected_capture` probabilities for the lower-5%, lower-10%, and lower-20% evaluations. Ranks 21–2,144 continue the same deterministic greedy complementarity objective for catalog exploration and are identified by `rank_scope = extended_greedy_order`; validated cumulative capture is left null beyond rank 20. `selection_incremental_gain_lower5` and `selection_objective_cumulative_lower5` describe the selection objective. `leave_one_out_loss_top5` is populated only where the frozen analysis formally calculated it.

## `coverage.json`

One row per evaluation target and panel size. `sequence_basis_target` is always `0.95`; `expected_capture` is a 0–1 probability; `measured_tail` provides the display label.

## `species_catalog.json`

One row per formal-binomial candidate species. Taxonomy, direct protective and warning support, broad life-stage category count, occurrence support, protective-evidence-volume tier, complete national rank, and testing-priority output are included. The tier is defined by distinct valid protective contexts: very limited = 1–4, limited = 5–19, moderate = 20–49, and strong = at least 50. The separate chemical count records unique chemicals. These counts describe evidence volume and are not biological sensitivity estimates.

## `regional.json`

One row per state with at least one eligible priority chemical in the frozen state-weight table. Supported states contain a complete localized sequence, fixed national Top-5 comparison, overlap, expected capture, and gain in percentage points. States with fewer than three eligible priority chemicals are retained with `status = insufficient_support` and a reason.

## Downloads

The `downloads/` directory contains flattened CSV versions of the four explorer modules. JSON and CSV values are generated in the same run. `downloads_manifest.json` lists file sizes and SHA-256 checksums.
