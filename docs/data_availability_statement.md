# Draft data-availability statement

Core analysis code and a static-results explorer will be archived in the approved GitHub repository and Zenodo release (DOI pending). Primary inputs include large public and provider-hosted resources such as the U.S. EPA ECOTOX Knowledgebase. These datasets are available from their official services and are not mirrored in the GitHub code repository because of their size and provider distribution arrangements. Official access links, provenance dates, and preparation contracts are documented in the repository. The archived software records the frozen analysis version, random seeds, dependency lock, input schemas, expected numerical checkpoints, and source-output checksums. Any separately approved author-generated data deposit will be cited here by its final DOI before publication.

This statement is a release draft. Replace all pending identifiers only after the corresponding repository and archive exist; do not invent a DOI.
